## The excuse

> I followed the plan perfectly. The plan was terrible. I wrote the plan.

## How it works

`main.py` is a deterministic program that writes the one-line excuse above
to `/output/entry.txt`. Nothing else is written; the output is a single line of
71 characters. The program refuses to run if the excuse ever leaves the 1–200
character gate, contains a newline, or has leading/trailing whitespace.

Run it locally (the grader sandbox writes to `/output`):

```sh
python3 main.py
```
